# IT Troubleshooting Lab

A reproducible Windows help-desk practice lab covering connection settings, NTFS file permissions, and application health. The focus is diagnosing a symptom, collecting evidence, applying a targeted fix, and checking the result.

**Status:** the exercise toolkit is prepared. The owner's hands-on runs, screenshots, and incident reports are pending. The scenarios and service are synthetic; expected results below are not claims of completed work.

| Incident | What to investigate | Skills practiced | Owner evidence |

## Run it in VS Code

Use Windows 11, Windows PowerShell, and Python 3.10 or newer. The permission exercise needs a local NTFS folder owned by your Windows account. Use an ordinary user terminal. WSL, the university server, administrator access, and Python package installation are not needed for these exercises.

1. Download this repository with **Code > Download ZIP** and extract it.
2. Open the inner folder containing **`lab.py`** in VS Code.
3. Select **Terminal > New Terminal** and run:

```powershell
py lab.py setup
py lab.py serve
```

4. Keep that terminal open. Open a second terminal in the same folder and run:

```powershell
py lab.py check
```

Expected baseline: `PASS: TCP connected to port 8765; application returned HTTP 200 (healthy).`

Open [the local lab page](http://127.0.0.1:8765) if you want to see the service in your browser. Follow [Start here](docs/START-HERE.md), then the incidents in order. The walkthroughs provide the commands; writing new code is not part of completing the exercises.

## How the environment works

The Python program provides a small local HTTP service and a separate client check. Two configuration files let the client point to the wrong port without changing the server. A service-state file introduces a controlled HTTP 503 response. Logs are generated by this exercise only.

The PowerShell exercise creates one synthetic report, saves its original file permissions, and introduces an explicit deny rule for the current account. Repair restores that file's saved permissions. It does not create Windows accounts or change permissions on personal folders.

| Location | Purpose |
| --- | --- |
| `lab.py` | Local service, client checks, and configuration exercises |
| `scripts/permissions.ps1` | Windows file-access exercise |
| `docs/` | Walkthroughs, setup, and testing notes |
| `cases/` | Incident-report templates to complete after each run |
| `evidence/` | Reviewed screenshots and selected observations |
| `.lab/`, `.permission-lab/` | Generated local data; ignored by Git |
